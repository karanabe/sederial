# RFC compliance and limits

## RFC support

The scope below covers requirements relevant to conditional forwarding. Tests
link to their source files and are representative regression checks; they do
not establish full conformance to every RFC or extension.

| RFC / area | Supported behavior | Corresponding tests |
| --- | --- | --- |
| [RFC 1034 §3.1](https://www.rfc-editor.org/rfc/rfc1034.html#section-3.1), [RFC 1035 §2.3](https://www.rfc-editor.org/rfc/rfc1035.html#section-2.3), [RFC 1123 §2.1](https://www.rfc-editor.org/rfc/rfc1123.html#section-2.1): names | Binary labels, ASCII case-insensitive comparison, leading-digit names, root names, and 63-octet label / 255-octet expanded-name limits. | [names_preserve_binary_labels_and_enforce_limits](src/dns/tests.rs) |
| [RFC 1035 §4.1](https://www.rfc-editor.org/rfc/rfc1035.html#section-4.1): wire format and compression | Header, question, record-envelope and common RDATA validation; compressed-name decoding with invalid pointer rejection. Unknown RDATA remains opaque within its declared length. | [header_and_question_vector](src/dns/tests.rs), [compression_rfc1035_section_4_1_4](src/dns/tests.rs), [hostile_compression_and_labels](src/dns/tests.rs) |
| [RFC 1035 §7.3](https://www.rfc-editor.org/rfc/rfc1035.html#section-7.3): response correlation | Check the upstream endpoint, QR, transaction ID, opcode and complete question before accepting a response. | [response_correlation_and_safe_truncation](src/dns/tests.rs), [invalid_udp_responses_are_ignored_until_correlated_reply](tests/forwarding.rs) |
| [RFC 1035 §4.2.1](https://www.rfc-editor.org/rfc/rfc1035.html#section-4.2.1), [RFC 1123 §6.1.3](https://www.rfc-editor.org/rfc/rfc1123.html#section-6.1.3): UDP and fallback | Retry truncated UDP responses over TCP; generate a safe TC response when the answer exceeds the client's UDP limit; bound retries and failover. | [truncated_udp_retries_tcp_and_respects_client_size](tests/forwarding.rs), [unavailable_upstreams_return_servfail](tests/forwarding.rs) |
| [RFC 1035 §4.2.2](https://www.rfc-editor.org/rfc/rfc1035.html#section-4.2.2), [RFC 7766](https://www.rfc-editor.org/rfc/rfc7766.html): TCP | Two-byte framing, partial reads/writes, pipelined requests and connection reuse. | [RFC 6891 §§6–7](https://www.rfc-editor.org/rfc/rfc6891.html#section-6): EDNS | EDNS version zero, OPT placement/uniqueness/length checks, extended RCODEs and BADVERS. | [RFC 8914](https://www.rfc-editor.org/rfc/rfc8914.html): extended DNS errors | Preserve opaque EDE and the original bytes of the last validated SERVFAIL/REFUSED after failover within the selected group. ## Deliberate limits

| Area | Limit and intended behavior | Corresponding tests |
| --- | --- | --- |
| Routing | Match only the original QNAME by complete labels and longest suffix. Failover stays within the selected group, without falling back to default servers. Reverse lookups need explicit `in-addr.arpa` / `ip6.arpa` routes; this does not enforce policy on CNAME targets or names inside RDATA. | [exact_subdomain_longest_boundary_default_and_reverse](src/routing.rs), [private_route_failures_never_contact_default_over_udp_or_tcp](tests/forwarding.rs) |
| Parser and UDP size | Compression chains are limited to 128 pointers to bound work. UDP replies use 512 bytes without EDNS, or the advertised size clamped to 512–1232 bytes with EDNS; larger answers receive TC. | [hostile_compression_and_labels](src/dns/tests.rs), [edns_size_options_version_and_generated_errors](src/dns/tests.rs), [udp_ceiling_truncates_large_edns_answer_but_tcp_keeps_it](tests/forwarding.rs) |
| TCP scheduling | Process pipelined requests sequentially and reply in order to keep resource ownership bounded. Concurrent processing within one connection, recommended by RFC 7766, is deferred. | [tcp_fragmentation_pipelining_and_upstream_connection_reuse](tests/forwarding.rs) |
| Cookie compatibility and byte preservation | Accept a missing Cookie on the initial exchange with an endpoint for legacy compatibility; require it after a validated BADCOOKIE challenge. If replacing a Cookie would move later bytes, send the unchanged query over TCP to preserve opaque data and compression offsets. | [cookie_unaware_servers_remain_compatible_on_the_first_exchange](tests/forwarding.rs), [cookie_before_padding_unknown_option_or_additional_rr_uses_tcp_without_moving_bytes](tests/forwarding.rs) |
| Cookie local errors | Local errors contain no Cookie and are suppressed when a fully parsed request supplied a Server Cookie. Parse-error FORMERR uses only safe partial context, so a client expecting a Cookie may discard it. Sederial cannot authenticate a local Server Cookie. | [response_cookie_lengths_and_local_error_policy](src/dns/cookie.rs), [structured_opt_mutations_retain_only_safe_error_context](src/dns/tests.rs) |
| Failover | SERVFAIL, REFUSED and transport failures try another server in the selected group. NXDOMAIN and NOERROR, including NODATA, are final. Identical UDP queries are not retransmitted. | [timeout_servfail_and_connection_failure_fail_over_but_nxdomain_is_final](tests/forwarding.rs), [refused_fails_over_but_nxdomain_is_final](tests/forwarding.rs) |
| Capacity and deadlines | Eight UDP workers / 64 queued packets and sixteen TCP workers / 16 queued connections bound load. A request has 5 seconds, including UDP queue wait; each upstream attempt has at most 2 seconds. All retries share that budget, so not every configured server is guaranteed an attempt. Expired requests are dropped. | [tcp_capacity_is_bounded_and_udp_stays_available](tests/operations.rs), [expired_udp_job_waiting_in_queue_never_reaches_any_upstream](src/server.rs), [tc_cookie_and_reused_tcp_share_the_original_request_budget](src/upstream.rs) |
| TCP frame deadlines | Each frame has 10 seconds, including accept-queue wait for the first frame. A complete request starts its 5-second budget; writing the response has at most 2 seconds, capped by the remaining request time. Partial progress does not reset a frame's deadline. | [framing_retains_partial_prefix_across_read_timeouts](src/transport.rs), [framing_deadline_is_absolute_despite_partial_progress](src/transport.rs) |

## Unsupported features

| Feature | Behavior / scope | Corresponding tests |
| --- | --- | --- |
| AXFR/IXFR and transaction authentication | Zone transfers, TSIG, TKEY and SIG(0) are refused. No multi-message transfer, signing or key negotiation is implemented. | [malformed_unsupported_and_unsolicited_packets_do_not_break_service](tests/operations.rs) covers transfer and TKEY/TSIG query-type rejection; no dedicated SIG(0) regression. |
| Non-QUERY operations | UPDATE, NOTIFY, IQUERY, STATUS and other non-QUERY opcodes receive NOTIMP. AD SRV queries work; AD dynamic DNS updates do not pass through. | [malformed_unsupported_and_unsolicited_packets_do_not_break_service](tests/operations.rs) covers IQUERY rejection; [split_dns_routes_ad_srv_reverse_and_default_over_both_transports](tests/forwarding.rs) covers SRV forwarding. |
| Full Cookie endpoint | No Server Cookie generation or cryptographic validation, global Cookie cache, or zero-question Cookie prefetch. Cookie checks establish correlation only. | [malformed_query_flags_and_missing_question_are_rejected](src/dns/tests.rs) covers zero-question rejection; [response_cookie_lengths_and_local_error_policy](src/dns/cookie.rs) covers local-error suppression. |
| Recursive, authoritative and security services | No iterative resolution, authoritative data, response cache, DNSSEC validation, client authentication or ACL. Restrict listener access to trusted clients. The full RFC 5625 transparency profile is not claimed because malformed packets and unsupported operations are rejected. | [edns_unknown_records_flags_and_options_survive](tests/forwarding.rs) covers pass-through; absent services have no dedicated tests. |
| Other services | No DoH/DoT, web UI, health database, DHCP, TFTP or PXE. | Not implemented; no dedicated tests. |
